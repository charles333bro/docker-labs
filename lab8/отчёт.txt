Лабораторная работа №8. Nginx reverse proxy и безопасность.

1. Настройка Nginx как reverse proxy и раздача статики
Nginx настроен как входная точка для приложения. Запросы к корню (/) раздают статические файлы из папки static/ (что подтверждается заголовком Server: nginx). Запросы к /api/ проксируются на контейнер с Flask (порт 5000).

2. Настройка HTTPS
Сгенерирован самоподписанный SSL-сертификат. В конфигурации Nginx настроен принудительный редирект с HTTP (порт 80) на HTTPS (порт 443) и указаны пути к сертификатам.

3. Безопасность и защита прав доступа
В конфигурацию Nginx добавлены заголовки безопасности: Strict-Transport-Security (HSTS), X-Frame-Options, X-XSS-Protection, X-Content-Type-Options.
Защита от SQL-инъекций обеспечивается использованием ORM SQLAlchemy. Проверка прав доступа (авторизация) реализована через JWT-токены на уровне API (лабораторная работа №6).

4. CORS
В приложении Flask настроен модуль Flask-Cors для контроля кросс-доменных запросов.
